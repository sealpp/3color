# 3color · 三色影相

复刻 Sergei Prokudin-Gorskii 三色摄影法的 PWA 相机：用手机后置摄像头，依次以红、绿、蓝三个通道曝光同一画面，再逐像素合成一张彩色照片，呈现早期彩色摄影的复古质感。

[English](./README.md)

## 历史背景

1909–1915 年，俄国摄影师 **Sergei Mikhailovich Prokudin-Gorskii** 受沙皇尼古拉二世资助，用一台改装相机走遍俄国，在玻璃干板上依次透过**红、绿、蓝三枚滤光片**对同一画面曝光三次，再以三色投影灯叠放回放，留下了世界上最古老的一批彩色照片。这批玻璃干板现藏于美国国会图书馆。

## 原理

1. 同一机位、同一构图，依次拍摄三张照片（拍摄间隔由你控制）
2. 每张只提取对应通道作为灰度图像：红版取 R、绿版取 G、蓝版取 B
3. 三张灰度版逐像素合并：`final.RGB = (红版R, 绿版G, 蓝版B)`
4. 画面中有移动物体时，三版错位会产生天然的彩色描边——这正是那个时代的摄影特征

## 功能

- **PWA**：可安装到主屏幕，离线可用
- **自动 / 手动** 两种拍摄模式：自动按设定间隔连拍三通道；手动逐次按快门
- **换版间隔滑轨**：0–8 秒可调，滑块实时显示秒数
- **复古滤镜**：棕褐分离色调、暖色抬黑、降饱和、暗角、颗粒，可一键对比原色合成
- **相册**：IndexedDB 本地相册，支持查看、分享、保存到系统相册
